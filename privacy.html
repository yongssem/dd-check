제1조 처리 목적과 최소 입력

뚝딱체크는 교사가 학생 출결과 관련 서류 제출상태를 기록하고 달력·이력·통계를 확인하는 도구입니다. 공식 출결 판정이나 학교의 기록관리 기준을 대신하지 않습니다. 출결 확인에 필요한 항목만 입력하고, 메모에는 상세 병력·가족 사정·연락처 등 불필요한 내용을 적지 않습니다.

질병결석·질병조퇴·질병지각·질병결과 등의 유형과 선택 메모에는 건강 상태 정보가 담길 수 있습니다. 학교는 실제 처리 범위와 근거를 확인합니다. 서류 제출상태 표시는 진단서·증빙파일 자체를 앱 서버로 올리는 기능과 다릅니다. 학생·학부모가 가입하거나 생년월일·전화번호·이메일을 입력하는 절차는 없습니다.

제3조 기기 저장과 외부 처리

학생 명렬과 출결 기록은 현재 교사 기기의 브라우저 저장소에 기록됩니다. 앱에는 이 학생자료를 공급자의 데이터베이스나 외부 API로 자동 전송하는 기능이 없습니다. JSON 백업 파일로 내려받거나 복원할 수 있습니다. 로컬 저장도 개인정보 처리이며, 개인정보를 처리하지 않는 서비스라는 뜻은 아닙니다.

웹페이지는 Vercel 호스팅을 이용하므로 IP·브라우저 등 일반 접속정보가 호스팅 인프라에서 처리될 수 있습니다. 이 접속정보의 처리와 학생 출결자료 본문의 기기 저장은 구분합니다. 호스팅 위치·운영정보 보유 범위를 전부 국내이거나 출결자료와 동시에 삭제된다고 보장하지 않습니다. Vercel 개인정보 안내

교사가 백업 파일을 공유드라이브·이메일 등으로 옮기는 경우에는 학교가 그 보관·공유 범위를 별도로 확인해야 합니다. 앱이 그런 외부 전송을 자동 수행하는 것은 아닙니다.

제4조 보관 기간과 남는 사본

기기에서 저장된 자료는 이용 교사가 삭제할 때까지 남을 수 있으며, 앱이 자동 만료일을 적용하지 않습니다. 학교가 실제 처리 목적과 기준에 맞춰 보관 필요성을 확인하고 불필요한 자료를 수동 정리합니다. 구체적인 학교 기기·백업자료 보유기준은 학교에서 확인·안내합니다. 학급 종료일에 맞춰 기기자료가 자동 삭제되는 기능은 없습니다.

  • 개별 출결 기록은 해당 기록의 삭제 버튼으로 지울 수 있습니다.
  • 학생 삭제는 연결된 출결 기록이 없어야 실행할 수 있으므로 연결 기록을 먼저 확인·정리해야 합니다.
  • 전체 출결 기록 삭제는 출결 기록만 비우고 학생 명렬·설정을 남깁니다. 삭제 직전 전체 자료의 복구사본도 저장하므로 모든 개인정보의 완전파기 버튼이 아닙니다.
  • 자료 변환 전·최근 복원 전·일괄 삭제 전 사본이 브라우저에 별도로 남을 수 있고, 내려받은 JSON 파일은 앱에서 기록을 지워도 남습니다.

학교가 해당 기기의 앱 자료 전체 삭제를 결정하면, 담당자가 해당 앱 사이트의 저장자료 범위와 다른 자료에 미치는 영향을 확인한 뒤 브라우저의 해당 사이트 데이터 삭제 수단으로 본 데이터·복구사본을 정리할 수 있습니다. 내려받은 파일·외부 백업은 별도로 확인합니다. 다른 사이트나 브라우저 전체 기록을 무조건 지우는 절차가 아닙니다.

제5조 접근 환경과 안전한 관리

이 앱에는 교사별 로그인·역할 분리나 JSON 백업 암호화 기능이 없습니다. 해당 브라우저와 파일에 접근할 수 있는 사람이 자료를 볼 수 있으므로 학교는 관리 기기의 OS 잠금·개별 계정 사용·화면 노출·백업 파일 권한을 관리합니다. 학생자료가 담긴 기기나 백업을 공용 계정·공개 링크로 공유하지 않습니다.

공개 웹페이지는 HTTPS로 제공됩니다. 앱의 기기 저장을 암호화된 보관함이나 공급자가 원격 삭제할 수 있는 저장소로 설명하지 않습니다.

제6조 만 14세 미만 학생과 건강 관련 기록

학생이 직접 가입하지 않는 교사 기록 도구라도 학생 개인정보 보호 절차는 필요합니다. 학교는 출결·질병 유형과 메모의 처리근거를 확인하고, 필요한 범위의 법정대리인 동의와 학생 보호 절차를 안내합니다. 자세한 병명·병력이나 불필요한 진단서 내용을 메모에 옮기지 않습니다.

  1. 학교·담임교사는 사용 목적과 처리근거, 필요한 항목과 선택 기능을 먼저 확인합니다. 동의가 필요한 범위는 실제 자료를 입력하기 전에 학교의 기존 절차로 법정대리인 관계와 동의를 확인합니다.
  2. 학부모와 학생에게 처리 항목·저장 위치·공유 범위·삭제 방법·권리행사 연락처를 안내합니다. 학교는 확인한 범위에서만 자료를 입력·활용하고, 동의·철회 확인은 학교의 기존 관리 체계에서 처리합니다.
  3. 확인이 끝나지 않은 실제 학생 자료를 먼저 입력하지 않습니다. 가상자료나 종이 등 개인정보를 입력하지 않는 대체활동으로 참여를 지원합니다.
  4. 앱 입장, 별명 입력 또는 공급자 본인의 에듀집 제출 동의서는 법정대리인 동의를 대신하지 않습니다. 앱에 법정대리인 본인확인·전자동의 기능이 있다고 안내하지 않습니다.
  5. 불필요한 병력·가족 사정·연락처 등을 자유글에 적지 않도록 안내하고, 잘못 입력하거나 공개된 자료는 담임교사 또는 보호책임자에게 알려 새 입력·활용을 중단하고 수정·삭제를 요청합니다.

제7조 열람·정정·삭제·처리정지 요청

  1. 학생·법정대리인은 담임교사 또는 아래 보호책임자에게 열람·정정·삭제·처리정지를 요청할 수 있습니다. 대상 앱·학급·학생과 요청 범위를 알려 주세요. 필요한 범위에서 본인·대리인 관계를 확인합니다.
  2. 담임교사는 보유한 자료와 실제 관리 화면의 기능으로 조치하고, 처리되지 않는 범위는 보호책임자에게 지원을 요청합니다. 기능에 없는 즉시 계정정지나 모든 사본의 일괄 삭제를 약속하지 않습니다.
  3. 접수 후 대상 범위·진행 상황·조치 결과를 요청자에게 안내합니다. 문의·권리행사 접수 시 자발적으로 제공한 연락처와 요청 내용은 해당 문의를 확인·처리하는 데 필요한 범위에서 사용하며, 학급 학생자료와 구분하여 취급합니다.

공급자가 교사 기기의 출결자료를 원격 열람·수정·삭제하는 기능은 없습니다. 기기자료에 대한 조치는 자료를 관리하는 교사가 해당 기기에서 수행하고, 보호책임자는 실제 기능과 사본 정리 방법을 안내합니다.

제8조 제3자 제공과 위탁의 구분

앱에는 학생 출결자료를 공급자 서버에 수집하거나 제3자에게 자동 제공하는 기능이 없습니다. 일반 호스팅 접속정보 처리와 문의 접수는 제3조·제9조에 따로 안내하며, 학교가 파일을 외부에 보관·공유한다면 학교의 실제 절차에서 대상·목적·범위를 확인합니다. 학생자료 자동 전송이 없다는 사실을 서비스와 관련한 모든 외부 처리가 없다는 뜻으로 확대하지 않습니다.
